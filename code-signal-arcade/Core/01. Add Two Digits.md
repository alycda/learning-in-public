> given a two-digit integer `n`. Return the sum of its digits.

### PseudoCode
1. coerce to string
2. split into array
3. map back to Number
4. reduce to sum
## ecmascript

```typescript
let solution = (n: number): number => 
  // [...String(n)].reduce((r, v) => r + Number(v), 0)
  // Math.floor(n / 10) + n % 10;
  (n + "").split('').map(Number).reduce((x, y) => x + y)
```

## Python

```python
def solution(n):
  return n // 10 + n % 10 #since it is always a 2-digit number, we can floor divide by 10 and then return the remainder
```

## C++

```c++
int solution(int n) {
  return n % 10 + n / 10;
}
```

## Rust

```rust
fn solution(n: i32) -> i32 {
  n % 10 + n / 10
}
```
