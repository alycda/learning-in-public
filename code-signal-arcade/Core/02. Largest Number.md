> Given an integer `n`, return the largest number that contains exactly `n` digits.

### PseudoCode
1. power of 10 minus 1?
## ecmascript

```typescript
let solution = (x: number) => (10**2) - 1
```

## Python

```python
def solution(n):
  return 10 ** n - 1
```

## C++

```c
int solution(int n) {
  return (int)pow(10, n) - 1;
}
```

## Rust

```rust
fn solution(n: i32) -> i32 {
  10_i32.pow(n as u32) - 1
}
```
