> Given the string, check if it is a [palindrome](keyword://palindrome).

### PseudoCode
1. loop through indices at start and end of string until they meet or don't match

![[verbose 1.png]]

## ecmascript

```typescript
let solution = (inputString: string) => 
  inputString == inputString.split('').reverse().join('')
```

## [[Python]]

```python
def solution(inputString):
  return inputString == inputString[::1] # pythonic
```

## [[C]] 

```c
bool solution(char * s) {
  char *q = s + strlen(s) - 1;

  while (q > s) {
    if (*q-- != *s++)
    return false;
  }

  return true;
}
```

## [[C++]]

```c++
bool solution(string input) {
  return input == string(input.rbegin(),input.rend());
}
```

## [[Personal/Computer Science/Rust]]

fn solution(input_string: String) -> bool {
  input_string.chars().eq( input_string.chars().rev() ) // implicit return
}
