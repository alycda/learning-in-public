> Write a function that returns the sum of two numbers.

## [[Typescript]]

```typescript
let solution = (x: number, y: number): number => x + y;
```

## [[Personal/Computer Science/CS50/Python]]

```python
def solution(x, y):
  return x + y
```

## [[C]] / [[C++]]

```c
int solution(int x, int y) {
  return x + y;
}
```

## [[Personal/Computer Science/Rust]]

```rust
fn solution(x: i32, y: i32) -> i32 {
  x + y // implicit return (no semicolon)
}
```
