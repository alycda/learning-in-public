> Given an array of strings, return another array containing all of its longest strings.

## [[Python]]

```python
def solution(inputArray):
  m = max(len(s) for s in inputArray)
  r = [s for s in inputArray if len(s) == m]
  return r
```

```rust
fn solution(inputArray: Vec<String>) -> Vec<String> {
  let max = inputArray.iter().map(|s| s.len()).max().unwrap();
  
  inputArray.into_iter().filter(|s| s.len() == max).collect()
}
```
