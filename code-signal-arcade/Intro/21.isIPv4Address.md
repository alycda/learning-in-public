> An IP address is a numerical label assigned to each device (e.g., computer, printer) participating in a computer network that uses the Internet Protocol for communication. There are two versions of the Internet protocol, and thus two versions of addresses. One of them is the [IPv4 address](keyword://ipv4-address).
> 
> Given a string, find out if it satisfies the IPv4 address naming rules.

### PseudoCode
1. split on `.`
	1. must have exactly 4 blocks/parts
2. each block must be a numeric value, not coerced
	1. `''` != 0
	2. does not contain non-numeric characters (alpha, symbol/punctuation)
	3. no leading 0s or multiple 0s (`.00.`, `.000.`)

don't use a regex (won't return false for multiple 0's)
	`^(?:(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.){3}(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)$`
don't use reduce, use `.every`
## ecmascript

```typescript
let solution(inputString: string): boolean => {
  const blocks = inputString.split(".");

  if(blocks.length != 4) {
    return false
  }

  return blocks.every(current => {
    //console.log(current)

    if(!current || current > 255) {
      return false
    }

    if(!/^\d+$/.test(current)) {
      return false
    }

    // leading|multiple 0's
    if(/^0\d+$/.test(current)) {
      return false
    }

    return true
  })
}
```
