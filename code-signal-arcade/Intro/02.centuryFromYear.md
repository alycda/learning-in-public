#arcade #solved

> Given a year, return the century it is in. The first century spans from the year 1 up to and including the year 100, the second - from the year 101 up to and including the year 200, etc.

### PseudoCode
1. for years 1-100, return 1
2. if year is evenly divisible by 100, then return year/100
3. else add 1 to year / 100

![[verbose.png]]
## ecmascript

```typescript
let solution = (year: number) => Math.ceil(year/100)
```

## [[Python]]

```python
def solution(year):
  return (year + 99) // 100 # most pythonic
```

## [[C]] / [[C++]]

```c
int solution(int year) {
  return (year + 99)/100;
}
```
