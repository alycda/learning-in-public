> Given a string, find out if its characters can be rearranged to form a [palindrome](keyword://palindrome).

### PseudoCode
1. sort the string
2. if odd length, drop last character
	1. it can be the middle
3. pairs of tuples

*above is too memory intensive, alternative:*

1. create a dictionary to hold character counts
2. keep track of characters with odd counts
3. if more than 1 character has an odd count, it cannot be a palindrome
## ecmascript

```typescript
function solution(inputString: string): boolean {
  const set = new Set(); // faster than a dictionary object?

  inputString.split('').forEach((x) => {
    if (set.has(x)) set.delete(x) // if element already exists, remove it for remainder of 0
    else set.add(x) // remainder 
  })

  return set.size <= 1; // set can only have 0 or 1 remainders, else is not a "balanced" group of tuples
}
```

## Python

```python
def solution(inputString):
  return sum([inputString.count(i)%2 for i in set(inputString)]) <= 1
```

## Rust

```rust
use std::collections::HashMap;

fn solution(inputString: String) -> bool {
  let mut hm = HashMap::new(); 
  inputString.chars().for_each(|c| *hm.entry(c).or_insert(0) += 1);
  hm.values().filter(|&&v| v % 2 == 1).count() < 2 // implicit return
}
```
