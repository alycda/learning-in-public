> define an `n`-interesting polygon. Find the area of a polygon for a given `n`.

### PseudoCode
1. calculate area of middle
	1. n + n - 1
2. calculate area of half
	1. middle - 2 until < 1
3. then double the half and add to the middle
## ecmascript

```typescript
let solution = (n: number) => n * n + (n - 1) * (n - 1)
```

## [[Python]]

```python
def solution(n):
  return n**2 + (n-1)**2
```

## [[C]] / [[C++]]

```c
int solution(int n) {
  return (n * n + (n - 1) * (n - 1));
}
```
