> Given an array of integers, find the pair of adjacent elements that has the largest product and return that product.

## ecmascript

```typescript
let solution = (integerPairs) => 
  Math.max(...integerPairs.slice(1)
    .map((x, i) => [x * integerPairs[i]))
```

## [[Python]]

```python
def solution(integerPairs):
  return max([integerPairs[i] * integerPairs[i+1] for i in range(len(integerPairs)-1)])
```
