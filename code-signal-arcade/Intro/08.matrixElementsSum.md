> After becoming famous, the CodeBots decided to move into a new building together. Each of the rooms has a different cost, and some of them are free, but there's a rumour that all the free rooms are haunted! Since the CodeBots are quite superstitious, they refuse to stay in any of the free rooms, **or any of the rooms below any of the free rooms**.
> 
> Given `matrix`, a rectangular matrix of integers, where each value represents the cost of the room, your task is to return the total sum of all rooms that are suitable for the CodeBots (ie: add up all the values that don't appear below a `0`).

### PseudoCode
1. loop through columns
2. add to total if not 0
3. if 0 go to next column
## ecmascript

```typescript
function solution(matrix) {
	let badColumns = [],	
	total = 0
	
	for(let i = 0; i < matrix.length; i++) {
		const row = matrix[i]		
		// console.log('row:', i, row)
		
		for(let j = 0; j < row.length; j++) {
			const column = row[j]			
			// console.log('column:', j, column)
			
			if(column == 0) {			
				if(!badColumns.includes(j)) {
					badColumns.push(j)				
				}
			} else if (!badColumns.includes(j)) {				
				total = total + column
			}		
		}
	}
	
	return total
}
```

```rust
fn solution(matrix: Vec<Vec<i32>>) -> 132 {
  let row_1 = matrix[0]; // used only for readability
  let rows = matrix.len(); // used only for readability
  let mut sum = 0

  for col in 0 .. row_1.len() {
	for row in 0 .. rows {
	  if matrix[row][col] == 0 {
		break;
	  }
	  sum += matrix[row][col];
	}
  }

  sum // implicit return
}
```
